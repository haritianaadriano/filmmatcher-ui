# Color Combo for UI: InstantCrush

Bring a vibrant, futuristic vibe to your user interface with the **Sleek Neon Glow** palette—perfect for a modern, techy, and youth-oriented brand.

## Palette

| Role             | Color       | Hex       |
|------------------|-------------|-----------|
| Background       | Near-black  | `#0E0E10` |
| Primary Accent   | Neon Cyan   | `#00E5FF` |
| Secondary Accent | Neon Pink   | `#FF007A` |
| Highlight        | Neon Yellow | `#FFD600` |

## Why Choose This?

- Creates a **cyberpunk-inspired** atmosphere  
- Gives a sleek, high-tech feel  
- Eye-catching neon colors add energy and fun  
- Great for brands targeting younger, dynamic audiences
